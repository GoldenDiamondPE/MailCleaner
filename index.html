A PRIVATE WORKSPACE

Your inbox isn’t
our business.

MailCleaner connects directly to your mail providers and uses a model running on your computer. There’s no MailCleaner analytics service or hosted AI endpoint.

  • Dashboard and inference connections stay on loopback.
  • Mail actions only add labels. No deletion or archiving.
  • Local data includes email text and is not encrypted by the app. Protect your computer and backups.
  • Gmail tokens are stored locally. Bridge credentials stay in memory for the session.

Provider and inference software policies still apply. This public page has no connection to your inbox; a hosting provider may keep ordinary access logs.

GOOD TO KNOW

A few clear answers.

Does it delete or move my emails?

No. MailCleaner reads inbox messages and adds labels. It preserves existing labels, inbox placement, and read status. Updated names add new labels alongside the old ones.

Is the AI always right?

No. Small local models can misclassify messages. Start with previews and review sensitive mail before a large sort. Saved corrections help with exactly matching content; they do not train model weights.

What do I need to connect Gmail and Proton?

This beta requires your own Google Desktop OAuth client. Google’s Gmail permission is broad; MailCleaner only reads and labels. Proton requires Bridge with an eligible paid plan and its local IMAP details. The included guide walks through setup.

Can I run this as a public web server?

The mailbox dashboard is for local use only. It has no remote-user authentication or cloud mailbox architecture. This product page is separate static content; never publicly host the dashboard or private data directory.

What’s still being prepared for a wider release?

Release validation, a public Gmail OAuth verification path, a signed installer, a project license, and a maintainer/support contact. The source archive includes the release checklist and roadmap. No open-source license grant has been added yet.
